# 🚀 Growth Hacker AI Agent: Conversion Monitor

This project is an **Agentic AI Dashboard** designed to monitor product health and trigger autonomous growth strategies when performance metrics drop. 

### 🔗 Live Demo
**[View Live Dashboard](https://growth-hacker-agent.streamlit.app/)**

---

### 🛠️ The Problem & Solution
* **The Problem:** Traditional dashboards require constant human monitoring to catch conversion drops.
* **The Solution:** This agent monitors a SQL database of conversion rates. When a "crisis" is detected (e.g., a drop from 3.85% to 0.50%), it triggers an **AI Agent (TinyLlama)** to draft a technical recovery strategy automatically.

### 🏗️ Technical Stack
* **Frontend:** Streamlit (Python)
* **Backend:** SQLite (SQL)
* **AI Engine:** TinyLlama via Ollama
* **Data Analysis:** Pandas & NumPy
